# 证书存档

江苏电子信息职业学院,计算机与通信学院,23级。大学攒的这些证书都放这了,留个底,找工作或者评优的时候也方便翻。

奖状大多数是团队的,队友的名字都在证书上,就不单独写了。有些纸质版是手机拍的,效果一般,将就看看。

按类型分了下:

- [国家级](国家级/) — 全国赛、总决赛
- [省级](省级/) — 省赛、赛区
- [校级](校级/) — 学校里的
- [技能与语言证书](技能与语言证书/) — 英语、计算机等级
- [专利与软著](专利与软著/)
- [志愿服务](志愿服务/)
- [佐证与留档](佐证与留档/) — 公示名单、成绩公示、颁奖照片啥的

文件名都是「年份-赛事-奖项」,想找哪张直接搜。
